# 📱 วิธีการรันบน Android (All-in-One Edition)

คู่มือนี้จะสอนคุณใช้งาน **Sync Movie Watch (Android Edition)** ซึ่งเป็นไฟล์เดียวที่รวมทั้งระบบติดตั้งและระบบเซิร์ฟเวอร์ไว้ด้วยกันครับ

---

## 🛠️ ขั้นตอนที่ 1: ติดตั้งแอป Termux
1. เข้าไปที่ลิงก์ [F-Droid Termux](https://f-droid.org/en/packages/com.termux/)
2. เลื่อนลงไปด้านล่างหาคำว่า **"Download APK"** (เลือกเวอร์ชันที่เหมาะสมกับเครื่อง) แล้วติดตั้งให้เรียบร้อย
3. เมื่อเปิดแอปครั้งแรก ให้รอจนกว่าจะขึ้นหน้าจอคำสั่ง

---

## 🚀 ขั้นตอนที่ 2: เริ่มต้นใช้งานครั้งแรก

1. **ติดตั้ง Python ใน Termux:**
   ```bash
   pkg update && pkg upgrade -y
   pkg install python -y
   ```

2. **นำโปรเจคลงมือถือ:**
   ก๊อปปี้โฟลเดอร์โปรเจคไปไว้ในโฟลเดอร์ `Download` ของมือถือ จากนั้นสั่งย้ายเข้า Termux:
   ```bash
   termux-setup-storage
   cp -r /sdcard/Download/movie-sync ~/
   cd ~/movie-sync
   ```

3. **รันโปรแกรมติดตั้งและเซิร์ฟเวอร์:**
   ```bash
   python movie_sync_android.py
   ```

---

## ⚙️ ขั้นตอนที่ 3: เมนูการใช้งาน

เมื่อรูนโปรแกรมขึ้นมา คุณจะพบกับ 4 เมนูหลัก:

1. **🚀 เลือกเมนู 3 (ในครั้งแรกที่ใช้งาน):** เพื่อติดตั้งระบบ Cloudflared, Zsh และระบบแนะนำคำสั่ง (จางๆ) อัตโนมัติ
2. **🚀 เลือกเมนู 1:** เมื่อต้องการเริ่มเซิร์ฟเวอร์และสร้างลิงก์สำหรับแชร์ให้เพื่อน
3. **🏠 เลือกเมนู 2:** สำหรับดูคนเดียวในเครื่องตัวเอง
4. **❌ เลือกเมนู 0:** เพื่อปิดโปรแกรม
