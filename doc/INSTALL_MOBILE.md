# 📱 คู่มือการติดตั้งสำหรับมือใหม่ (Android / Termux) 🎬

ยินดีด้วยครับ! ถ้าคุณมีแอป **Termux** ในเครื่องแล้ว เรามาเริ่มเปลี่ยนมือถือของคุณให้เป็นเซิร์ฟเวอร์ดูหนังส่วนตัวกันเลย ทำตามขั้นตอนง่ายๆ ด้านล่างนี้ได้เลยครับ

---

### Step 1: เตรียมความพร้อมพื้นฐาน
เมื่อเปิดแอป Termux ครั้งแรก ให้คัดลอกคำสั่งด้านล่างนี้ไปวางแล้วกด Enter ครับ (ทีละบรรทัด)

1. **ขอสิทธิ์เข้าถึงไฟล์ในเครื่อง:**
   ```bash
   termux-setup-storage
   ```
   *(จะมีหน้าต่างเด้งขึ้นมาถาม ให้กด **Allow** หรือ **อนุญาต** ครับ)*

2. **อัปเดตระบบพื้นฐาน:**
   ```bash
   pkg update && pkg upgrade -y
   ```

3. **ติดตั้ง Python (พระเอกของเรา):**
   ```bash
   pkg install python -y
   ```

---

### Step 2: เข้าสู่โฟลเดอร์โปรเจค
สมมติว่าคุณเอาโฟลเดอร์โปรเจคไว้ในโฟลเดอร์ Download ของมือถือ ให้พิมพ์คำสั่งนี้ครับ:
```bash
cd /sdcard/Download/ดูหนัง
```
*(ถ้าคุณเปลี่ยนชื่อโฟลเดอร์หรือเก็บไว้ที่อื่น ให้เปลี่ยนชื่อตามจริงนะครับ)*

---

### Step 3: ติดตั้งระบบอัตโนมัติ (ทำแค่ครั้งเดียว)
รันไฟล์ติดตั้งที่เราเตรียมไว้ให้:
```bash
python moblie.py
```
เมื่อเมนูเด้งขึ้นมา ให้เลือก **ข้อ 3 (⚙️ ติดตั้ง/อัปเดตระบบ Android)** ครับ
- ระบบจะลงโปรแกรมที่จำเป็นทั้งหมดให้ (Cloudflared, Zsh, NodeJS ฯลฯ)
- **สำคัญ:** ระหว่างติดตั้งอาจจะมีถามคำถาม ให้กด Enter ผ่านไปได้เลยครับ
- เมื่อเสร็จแล้ว ระบบจะสร้างทางลัดให้คุณพิมพ์คำว่า `movie` ได้ทันทีในครั้งหน้า!

---

### Step 4: วิธีเริ่มดูหนังกับเพื่อน
หลังจากติดตั้งเสร็จแล้ว (และแนะนำให้ปิดแอป Termux แล้วเปิดใหม่) ให้ทำดังนี้:

1. พิมพ์คำสั่งสั้นๆ: `movie`
2. เลือก **ข้อ 1 (🚀 เริ่มระบบ Cloudflare)**
3. รอจนกว่าจะเห็นลิงก์สีฟ้าๆ ที่ลงท้ายด้วย `.trycloudflare.com`
4. **คัดลอกลิงก์นั้นส่งให้เพื่อน!** และคุณเองก็สามารถเปิดลิงก์นั้นใน Chrome เพื่อเริ่มหาหนังดูได้เลย

---

### 💡 เคล็ดลับ "ดูยาวๆ ไม่หลุด"
เพื่อให้เซิร์ฟเวอร์ทำงานราบรื่นแม้คุณจะพับหน้าจอไปแชทหรือดูหนัง:

1. **ตั้งค่าแบตเตอรี่ (สำคัญมาก!):**
   - ไปที่ **Settings (ตั้งค่า)** > **Apps** > **Termux**
   - เลือก **Battery** > เปลี่ยนเป็น **Unrestricted (ไม่จำกัด)**
2. **ติดตั้งเป็นแอป (PWA):**
   - เมื่อเปิดลิงก์ใน Chrome ให้กดปุ่ม 3 จุด > เลือก **Add to Home Screen**
   - คุณจะได้ไอคอนแอปบนหน้าจอ ใช้งานเหมือนแอปจริงและพรีเมียมสุดๆ

---

### 🛠️ ปัญหาที่พบบ่อย
- **ลิงก์เปิดไม่ได้:** รอประมาณ 5-10 วินาทีหลังจากรันคำสั่งเพื่อให้ระบบ DNS ทำงานครับ
- **พิมพ์ไทยไม่ได้ใน Termux:** ไม่เป็นไรครับ ระบบเว็บข้างในรองรับภาษาไทยเต็มรูปแบบ พิมพ์ชื่อห้องเป็นภาษาไทยได้เลย!

**พร้อมแล้วรันคำสั่ง `python moblie.py` แล้วเลือกข้อ 3 เลยครับ! ลุย!** 🚀
