# 🎬 Sync Movie Watch - ดูหนังซิงค์กันแบบพรีเมียม 🚀

**Sync Movie Watch** คือระบบ Web Application สุดล้ำที่ช่วยให้คุณและเพื่อนๆ สามารถดูหนังพร้อมกันแบบเรียลไทม์ผ่านอินเทอร์เน็ต ด้วยดีไซน์ที่สวยงาม (Glassmorphism) และระบบบล็อกโฆษณาอัจฉริยะ ทำให้การดูหนังของคุณลื่นไหลกว่าที่เคย!

---

## ✨ ฟีเจอร์เด่น (Premium Features)

- 💎 **Premium Tailwind CSS UI**: อัปเกรดหน้าเว็บใหม่ทั้งหมดด้วย **Tailwind CSS** ดีไซน์ทันสมัยแบบ Glassmorphism สวยหรู โดดเด่น พร้อมเอฟเฟกต์แอนิเมชันตอนกด (Hover & Active Effects) ที่สไตล์เดียวกับเว็บแอปพลิเคชันระดับโลก
- 🎥 **Real-time Sync**: ระบบซิงค์เวลาเล่นหนังที่แม่นยำสูง เมื่อเจ้าของห้องกดเล่น หยุด หรือเลื่อนวิดีโอ ทุกคนในห้องจะขยับตามทันที!
- 🛡️ **Advanced Ad-Block Engine**: 
  - ระบบ **Proxy Ad-Filter** ที่ระดับ Server ช่วยกรองสคริปต์โฆษณาออกตั้งแต่ต้นทาง
  - Popup **Adblock Setup โฉมใหม่** มีคำแนะนำแบบเจาะจงทั้ง PC และ มือถือ (Mobile Users) พร้อมปุ่มติดตั้งคลิกเดียว
- 💬 **Dynamic Interactive Chat**: 
  - ระบบแชทแบบเรียลไทม์ พร้อมแสดงเวลาส่งข้อความรูปแบบ 24 ชม. (ไทย)
  - **Fullscreen Notification**: แจ้งเตือนแชทแบบ Toast ลอยสวยงามด้านบนหน้าจอแม้ดูหนังเต็มจอ!
- 🌐 **Robust Cloudflare Tunnel**: 
  - ระบบ Readiness Check อัจฉริยะ รอให้ URL ฝั่ง Cloudflare พร้อมใช้งาน (HTTP 200) ก่อนเปิดเบราว์เซอร์อัตโนมัติ หมดปัญหาเปิดมาเจอหน้าเว็บ error 404
- ❤️ **Shared Emojis**: ระบบกดอีโมจิลอย (Emoji Blast) ที่ทุกคนในห้องจะเห็นเด้งขึ้นมาพร้อมกัน เพิ่มสีสันในการรับชม
- 🔒 **Privacy & Security**:
  - **Room Lock**: ระบบล็อคห้องสำหรับเจ้าของ เพื่อความเป็นส่วนตัวสูงสุด
  - **Source Cloaking**: ซ่อนร่องรอยและข้อมูลแหล่งที่มาของหนังทั้งหมดจาก Console และหน้าเว็บ เพื่อป้องกันลิขสิทธิ์
- 📱 **Fully Responsive**: ใช้งานได้ลื่นไหลทั้งบนคอมพิวเตอร์ แท็บเล็ต และมือถือ

## 🚀 วิธีเริ่มใช้งานอย่างรวดเร็ว (Quick Start)

ระบบใช้ **Cloudflare Tunnel** ซึ่งฟรี 100% เสถียรสูง และไม่ต้องสมัครสมาชิกใดๆ:

1. **เปิดโปรแกรม**: ดับเบิลคลิกไฟล์ `run.bat` หรือใช้คำสั่ง:
   ```bash
   python mv_pc.py
   ```
2. **เลือกตัวเลือก 1**: 🚀 **เริ่มด้วย Cloudflare (แนะนำ! ฟรี ไม่มีขีดจำกัด)**
3. **รอรับลิงก์**: ระบบจะติดตั้งทุกอย่างให้อัตโนมัติและเปิดเบราว์เซอร์พร้อมลิงก์สาธารณะให้ทันที!

---

## 🛠️ รายละเอียดเมนูการใช้งาน

โปรแกรมถูกออกแบบมาให้ใช้งานง่าย มี 4 ตัวเลือกหลัก:

1. 🚀 **Cloudflare Tunnel (แนะนำที่สุด!)**: 
   - **ฟรี 100%** และเสถียรที่สุด 
   - ไม่จำกัดจำนวนคนเข้า
   - ไม่ต้องสมัครสมาชิกหรือใส่รหัสผ่านใดๆ
   - ระบบจะดาวน์โหลดและตั้งค่า cloudflared ให้อัตโนมัติ
2. 🏠 **Local Server**: 
   - สำหรับดูคนเดียวหรือแชร์ในบ้าน (วง LAN/WiFi เดียวกัน)
3. 📖 **วิธีใช้งาน**: คู่มือสรุปสั้นๆ สำหรับผู้เริ่มต้น พร้อมเคล็ดลับ
4. 🛡️ **Auto AdBlocker Setup**: เปิดหน้าติดตั้ง Extension ยอดนิยม (AdBlock, Ghostery, uBlock) ทันที

## ⚙️ การตั้งค่าเพิ่มเติม (Optional)

สร้างไฟล์ `.env` เพื่อกำหนดค่าเริ่มต้น (ไม่จำเป็นสำหรับการใช้งานปกติ):
```env
DEFAULT_PORT=3000
```
*สำหรับ Cloudflare ไม่ต้องตั้งค่าใดๆ เพิ่มเติม ระบบจัดการทุกอย่างให้อัตโนมัติ*

1. **เลือกหนัง**: ในหน้าแรก คุณจะพบกับรายการหนังใหม่ล่าสุดพร้อมรูปโปสเตอร์สุดสวย ให้คลิกเลือกเรื่องที่ต้องการ

5. **เพลิดเพลิน**: เริ่มเล่นหนัง แล้วความสนุกจะซิงค์ถึงกันทุกคน!

## 📱 รองรับ Android (Termux)

คุณสามารถเปลี่ยนมือถือให้เป็นเซิร์ฟเวอร์ได้ง่ายๆ ด้วยสคริปต์เวอร์ชันพิเศษ:
- **ไฟล์รัน**: `mv_apk.py`
- **คู่มือการติดตั้ง**: อ่านละเอียดได้ที่ [ANDROID_INSTALL.md](./doc/ANDROID_INSTALL.md)
- **จุดเด่น**: มีเมนูติดตั้งระบบอัตโนมัติในตัว (One-click Setup) พร้อมแก้ปัญหาเว็บเปิดไม่ทันด้วย Readiness Check Ping Loop และระบบ Wake Lock กันระบบหลับ

---

## 🎨 เทคโนโลยีที่ใช้ (Tech Stack)

- **Backend (API & Web Server):** `Python 3` (Built-in `http.server` & `urllib`), ไม่ต้องพึ่งพา Node.js
- **Frontend (UI & Layout):** `HTML5`, `Vanilla JavaScript`, และอัปเกรดล่าสุดใช้ **`Tailwind CSS v3 (CDN)`** เพื่อความสวยงามตอบโจทย์ยุค Modern Web
- **Networking:** `Cloudflared Tunnel` ส่งต่อทราฟฟิกออกอินเทอร์เน็ตโดยไม่ต้อง Forward Port

## 🔒 ความปลอดภัยและความเป็นส่วนตัว

- **Auto-Delete**: ห้องที่ไม่มีกิจกรรมนานเกิน 60 วินาที จะถูกลบออกจากระบบอัตโนมัติเพื่อประหยัดทรัพยากร
- **No Data Stored**: ระบบไม่มีการเก็บข้อมูลส่วนตัวใดๆ ของผู้ใช้
- **Stealth Mode**: ไม่มีการแสดงข้อมูลเชิง Debug หรือ URL ของแหล่งที่มาใน Browser Console ของผู้ใช้ทั่วไป
